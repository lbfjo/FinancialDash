## Getting Started

### Creating Your Account

1. **Visit the Application**
   Navigate to the Finance Dashboard website

2. **Choose Your Sign-up Method**
   - **Email/Password**: Click "Sign Up" and enter your details
   - **GitHub OAuth**: Click "Sign in with GitHub" for quick access

3. **Complete Registration**
   - Enter your email address
   - Choose a secure password

**Option 1: Email/Password**
1. Click "Sign In" on the homepage
2. Enter your email and password
3. Click "Sign In"

**Option 2: GitHub OAuth**
1. Click "Sign in with GitHub"
2. Authorize the application (first time only)
3. You'll be automatically logged in

## Dashboard Overview

The dashboard is your financial command center, showing a complete overview of your finances at a glance.

### What You'll See

**Summary Cards**
- **Total Income**: All income for the current month
- **Total Expenses**: All expenses for the current month
- **Net Income**: Income minus expenses (your savings)
- **Transaction Count**: Number of transactions this month

**Visual Charts**
- **Income vs. Expenses**: Bar or line chart comparing income and expenses over time
- **Expense Breakdown**: Pie chart showing where your money goes
- **Account Activity**: Overview of transaction counts per account

**Recent Transactions**
- Last 10 transactions across all accounts
- Quick view of date, amount, category, and description

### Customizing Your View

You can filter data by:
- **Date Range**: View specific time periods
- **Accounts**: Focus on specific accounts
- **Categories**: See spending by category

## Managing Accounts

Accounts represent your financial accounts like checking, savings, or credit cards.

### Creating a New Account

1. **Navigate to Accounts**
   Click "Accounts" in the main navigation

2. **Click "Add New Account"**
   Look for the button in the top right

3. **Fill in the Details**
   - **Account Name**: e.g., "Chase Checking", "Savings Account"
   - All accounts are linked to your user automatically

4. **Save**
   Click "Create Account" to finalize

**Example Accounts:**
- Checking Account
- Savings Account
- Credit Card
- Cash
- Investment Account

### Viewing Account Details

1. Click on any account in the list
2. See all transactions for that account
3. View account summary and statistics

### Editing an Account

1. Find the account in your list
2. Click the "Edit" button
3. Update the account name
4. Click "Save Changes"

### Deleting an Account

>   **Warning**: You cannot delete accounts that have transactions. Delete all transactions first.

1. Find the account you want to delete
2. Click the "Delete" button
3. Confirm the deletion

## Tracking Transactions

Transactions are the core of your financial tracking - every income or expense you record.

### Adding a Transaction

1. **Navigate to Transactions**
   Click "Transactions" in the main menu

2. **Click "Add Transaction"**

3. **Fill in the Details**
   - **Amount**: Enter the transaction amount (e.g., 45.50)
   - **Account**: Select which account this transaction belongs to
   - **Category**: Choose the appropriate category
   - **Date**: Select when the transaction occurred
   - **Description**: (Optional) Add notes like "Whole Foods grocery run"

4. **Save**
   Click "Add Transaction"

**Example Transaction:**
```
Amount: $125.50
Account: Checking Account
Category: Groceries
Date: Jan 15, 2025
Description: Weekly grocery shopping at Trader Joe's
```

### Viewing Transactions

**List View**
- See all transactions in chronological order
- Most recent transactions appear first
- Filter by account, category, or date range

**Transaction Details**
- Click any transaction to see full details
- View associated account and category
- See when it was created

### Editing a Transaction

1. Find the transaction in the list
2. Click the "Edit" button
3. Modify any field (amount, account, category, date, description)
4. Click "Save Changes"

### Deleting a Transaction

1. Find the transaction
2. Click "Delete"
3. Confirm deletion

> =¡ **Tip**: Instead of deleting, consider editing if you made a mistake. This preserves your transaction history.

### Filtering Transactions

**By Account**
- Select an account from the dropdown
- See only transactions for that account

**By Category**
- Choose a category to filter
- Useful for tracking specific spending areas

**By Date Range**
- Select start and end dates
- View transactions for specific periods

## Tips & Best Practices

### Recording Transactions

1. **Be Consistent**: Record transactions regularly (daily or weekly)
2. **Be Detailed**: Add descriptions to remember what each transaction was for
3. **Categorize Properly**: Accurate categories lead to better insights
4. **Record Everything**: Include small purchases - they add up!

### Setting Up Categories

1. **Start Simple**: Use the pre-loaded categories first
2. **Customize Later**: Add specific categories as you need them
3. **Keep It Organized**: Don't create too many similar categories
4. **Review Regularly**: Merge or delete unused categories

### Managing Accounts

1. **One Account per Real Account**: Create accounts that match your real-world accounts
2. **Include Cash**: Don't forget to track cash transactions
3. **Credit Cards**: Track as separate accounts to monitor debt

### Monthly Review

At the end of each month:
1. Review your income vs. expenses
2. Identify top spending categories
3. Look for unusual or unexpected expenses
4. Set goals for the next month

### Data Entry Shortcuts

- Use consistent descriptions for recurring transactions
- Set up accounts for all your financial sources
- Review and categorize uncategorized transactions weekly

## Troubleshooting

### Common Issues

#### "Cannot Delete Account"
**Problem**: Account has existing transactions

**Solution**:
1. Go to Transactions
2. Filter by the account you want to delete
3. Delete all transactions for that account
4. Now you can delete the account

#### "Cannot Delete Category"
**Problem**: Category is used in transactions

**Solution**:
1. Go to Transactions
2. Filter by the category
3. Either delete transactions or change them to a different category
4. Then delete the category

#### "Transaction Not Showing"
**Problem**: Recently added transaction doesn't appear

**Solution**:
1. Refresh the page
2. Check if you're viewing the correct date range
3. Verify you're not filtering by account or category

#### "Numbers Don't Add Up"
**Problem**: Summary totals seem incorrect

**Solution**:
1. Check the date range you're viewing
2. Verify all transactions are categorized correctly
3. Ensure income is marked as "Income" type, not "Expense"
4. Refresh the dashboard

### Getting Help

If you encounter issues not covered here:
1. Check the README.md file
2. Review the API documentation
3. Open an issue on GitHub
4. Contact support

## Privacy & Security

### Your Data

- All your data is private and isolated to your account
- Other users cannot see your transactions
- Your data is stored securely in a PostgreSQL database

### Best Practices

1. **Use a Strong Password**: Mix uppercase, lowercase, numbers, and symbols
2. **Keep Credentials Secret**: Never share your password
3. **Log Out**: Always log out on shared computers
4. **Regular Updates**: Keep your password updated

## Glossary

**Account**: A financial account like checking, savings, or credit card

**Category**: A classification for income or expenses (e.g., Groceries, Salary)

**Transaction**: A single financial event - money coming in or going out

**Net Income**: Total income minus total expenses (your savings/deficit)

**Dashboard**: The main overview page showing your financial summary
